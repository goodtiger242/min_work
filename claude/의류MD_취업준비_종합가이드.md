의류 MD 취업 준비 가이드


1. 직무 구분

의류/패션 MD 채용은 실제 업무 기준으로 네 갈래로 나뉜다.

- 온라인MD / AMD (27건, 가장 많음) — 자사몰·입점몰(무신사, 29CM 등) 상품 운영
- 기획MD / 상품기획MD (17건) — 시즌 상품 기획, 소싱, 트렌드 리서치
- 바잉MD / 수출MD (8건) — 해외 소싱·바잉, 수출입, 벤더 협상
- 영업MD (5건) — 매장·유통채널 재고 배분, 로테이션 관리


2. 온라인MD / AMD

- 업무: 상품 등록, 기획전·프로모션 세팅, 매출·재고 관리, 상품 촬영 및 스케줄 관리
- 자격요건: 경력 1~3년(주니어) 또는 5년 이상(팀장급)으로 양극화, 자사몰·입점몰 운영 경험, 엑셀 기반 매출·재고 관리 능력
- 우대사항: 아이폰 촬영 경험, 무신사·29CM·W컨셉 등 플랫폼 운영 경험, 카페24·사방넷 사용 경험, 포토샵(상세페이지·배너), SNS 콘텐츠 운영


3. 기획MD / 상품기획MD

- 업무: 시즌 상품 기획, 소싱, 트렌드 리서치, 생산 수량·가격 결정
- 자격요건: 경력 3~15년(범위 넓음), 시즌 기획 실무 경험, 영어(해외 소싱·협업 관련 공고 다수)
- 우대사항: 동대문 시장 소싱 경험, OTB(매입 예산 계산)·리오더 개념 이해, 포트폴리오 보유


4. 바잉MD / 수출MD

- 업무: 해외 공장·브랜드 발굴, 가격·수량·납기 협상, 생산~통관~입고 일정 관리
- 자격요건: 해외 소싱·수입 브랜드 MD/바이어 경력, 영어(TOEIC 900점 명시 사례 있음), 중국 소싱은 중국어(HSK 5급 이상) 요구
- 우대사항: OTB 계산·세일즈 데이터 분석, 해외 출장 결격사유 없음, 거래처 네트워크


5. 영업MD

- 업무: 매장·채널별 상품 배분, 재고 로테이션, 판매 데이터 기반 배분 전략
- 자격요건/우대사항: 타 직무 대비 느슨함, 학력·전공보다 유통 실무 이해도 중시 → 신입 진입장벽이 상대적으로 낮음


6. 공통 채용 조건

- 지역: 강남구·성동구(성수)에 집중(전체의 1/3 이상), 경기는 성남시 분당구 위주로 9건(대체로 경력직)
- 학력: 70건 중 12건이 학력무관 명시, 전공 제한 드묾
- 고용형태: 정규직 64건 중 28건이 수습 3개월(또는 2개월) 명시 — 사실상 표준
- 급여: 70건 중 1건만 구체적 금액 공개, 나머지는 면접 후 결정 → 지원 전 시장 급여 수준 파악 필요
- 마감: 70건 중 21건이 상시채용(채용시 마감)


7. 준비 우선순위

1) 엑셀 기반 매출·재고 데이터 분석 (전 직무 공통 필수)
2) 포토샵/일러스트로 상세페이지·배너 제작
3) 관심 플랫폼(무신사/29CM 등) 1곳 심층 조사 — 입점 구조, 상품 등록·프로모션 방식
4) 포트폴리오 제작 (8절 참고)
5) 영어 또는 중국어 — 바잉MD/수출MD/기획MD 지원 시 우선순위 상승, 온라인MD/AMD 위주라면 낮춰도 무방


8. 포트폴리오 후보

능력별

- 엑셀·데이터 분석: 브랜드 하나를 정해 플랫폼 랭킹·판매 카테고리 조사 후 표/그래프로 정리, 또는 가상 재고 데이터로 회전율 분석
- 포토샵·디자인: AI 이미지 생성으로 모델컷·배경 제작 → 상세페이지 시안 완성
- 온라인몰 운영: 카페24 무료 체험판으로 가상 쇼핑몰 개설 → 상품 등록·기획전·배너 구성
- 상품기획: 특정 브랜드의 "다음 시즌 기획MD"를 가정해 시즌 컨셉·아이템 구성·가격대·타겟을 담은 기획서 작성
- SNS 콘텐츠: 가상/실제 브랜드 인스타그램 피드 기획 + AI 생성 콘텐츠로 캘린더 제작
- 해외 소싱: 관심 해외 시장(중국, 동남아 등) 트렌드·가격대 조사 후 소싱 제안서 작성

종합형 (여러 능력을 하나로)

- 가상 브랜드 A to Z: 브랜드 컨셉·타겟 설정 → 시즌 기획서 → AI 룩북 → 상세페이지 시안 → SNS 콘텐츠 계획 → 매출/재고 목표까지 한 세트로 완성. 폭넓게 어필할 때 적합
- 실존 브랜드 벤치마킹 + 개선안: 실제 브랜드의 온라인몰 운영·상품 구성 분석 후 개선안과 상세페이지 리디자인 시안 제시. 온라인MD 지원에 적합, 면접에서 구체적 논의 가능
- AI 룩북 + 시즌 기획서 세트: 특정 시즌 트렌드 리서치와 기획서 작성 → AI로 해당 컨셉의 룩북 이미지 제작 → 비주얼 프레젠테이션으로 완성. 기획MD 지원에 적합, 신입도 완성도 있는 결과물 가능


용어

- MD/AMD: 상품 기획·관리 담당자 / 그 보조 역할
- 자사몰·입점몰: 회사 직영 쇼핑몰 / 무신사처럼 여러 브랜드가 입점하는 플랫폼
- 카페24·사방넷: 쇼핑몰 구축·통합 관리 프로그램
- OTB·리오더: 매입 예산 계산 / 잘 팔리는 상품 추가 발주
- 수습기간·상시채용: 정식 채용 전 평가 기간 / 마감일 없이 계속 모집

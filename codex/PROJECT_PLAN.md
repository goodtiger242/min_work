# 의류 MD 취업 지원 도구 — 프로젝트 정리

작성일: 2026-09-06
상태: 기획 및 브라우저 샘플 확인 단계. 수집 자동화 프로그램은 아직 구현하지 않음.

## 1. 만들려는 것

친구가 의류 MD 취업을 준비하면서 여러 채용 사이트를 반복해서 확인하는 수고를 줄이는 개인용 도구를 만든다. 관련 공고를 한곳에서 확인하고, 어떤 회사에 지원하고 자기소개서를 쓸지 판단할 수 있도록 돕는다.

공고 목록을 보여주는 데서 끝내지 않고, 여러 회사의 업무·자격요건·우대사항을 축적해서 해당 직무에 공통으로 필요한 역량을 파악하는 것이 또 하나의 핵심 목적이다.

상업적 서비스가 아니라 친구의 취업 준비를 위한 용도다. 최종적으로 친구에게 전달해서 사용할 수 있는 프로그램을 만드는 것이 목표다.

## 2. 현재 정한 검색 범위

- 직무: 의류 MD.
- 근무 지역: 서울특별시, 경기도.
- 경력, 학력, 급여, 고용 형태 등 다른 조건은 제한하지 않는다.
- 검색어 기본값은 ‘의류 MD’로 한다.
- 누락 방지를 위해 ‘패션 MD’, ‘의류기획MD’, ‘패션 온라인MD’ 등을 보조 검색어로 사용하는 방안을 검토한다. 검색 결과의 실제 업무가 의류 관련인지 확인한다.
- 지원할 공고와 마감된 분석 참고 공고를 구분한다.

## 3. 공고별로 모을 정보

| 구분 | 내용 |
|---|---|
| 출처 | 사이트명, 공고 식별자, 원문 링크, 확인 날짜 |
| 회사 | 회사명, 브랜드명, 공고에 공개된 회사 소개 |
| 채용 | 공고 제목, 모집 직무, 모집 인원(기재 시) |
| 업무 | 담당 업무와 역할 |
| 필수 조건 | 경력, 학력, 직무 경험, 역량 등 자격요건 |
| 우대 조건 | 우대 경험, 도구 활용, 자격증, 외국어 등 |
| 근무 조건 | 실제 근무지, 고용 형태, 급여, 근무 시간, 수습 여부 |
| 지원 정보 | 접수 기간, 마감 상태, 지원 방법, 제출 서류 |
| 데이터 상태 | 미기재, 읽기 실패, 원문 검증 필요 여부 |

필수 조건과 우대 조건을 섞지 않는다. 회사 주소와 실제 근무지를 구분한다. 없는 내용을 추측해서 채우지 않는다. 연락처 등 채용 담당자 개인정보는 기본 수집 대상에 포함하지 않는다.

## 4. 필요한 기능

### 공고 확인

- 여러 사이트의 관련 공고를 한곳에 모아 확인한다.
- 새 공고, 마감일, 지원 여부를 확인한다.
- 원문으로 바로 이동할 수 있게 한다.
- 같은 회사의 동일 공고가 여러 사이트에 올라오면 중복을 묶는다.
- 매일 갱신하는 것이 목표이며, 실행 방식과 시간은 아직 정하지 않았다.

### 직무 준비 분석

- 공고에서 반복되는 업무, 필수 역량, 우대 역량을 집계한다.
- 기획MD와 온라인MD처럼 역할이 다른 공고는 구분해서 분석한다.
- 어떤 공고를 근거로 나온 분석인지 원문 링크로 확인할 수 있게 한다.
- 적은 샘플에서 나온 경향을 전체 채용 시장의 통계처럼 표현하지 않는다.

### 친구가 사용할 화면

‘지원할 공고’와 ‘직무 준비 분석’을 중심으로 구성하는 방안을 우선 검토한다. 지원 상태를 관리하는 기능도 후보에 포함한다. 웹앱, PC 프로그램 등 최종 전달 형태는 아직 확정하지 않았다.

## 5. 수집 방식의 현재 상황

사람인 API는 신청했고 승인을 기다리는 중이다. 잡코리아 API는 개인 이용 승인을 확보하지 못했다.

API 없이도 실제 크롬 브라우저에서 검색 결과와 공고 상세 페이지를 열고, 본문 로딩을 기다린 다음 화면에 표시된 텍스트를 읽는 방식으로 샘플을 확인했다. 이번 테스트는 API 키 없이 진행했다.

이는 브라우저 도구로 직접 열람한 테스트다. 매일 실행되는 독립적인 크롤러나 친구에게 전달할 자동화 프로그램이 완성된 것은 아니다. 천천히 접근한다고 모든 공고의 열람이 보장되는 것도 아니다.

향후에는 사이트별로 검색·상세 열람·로딩 확인 과정을 자동화하는 방안을 검토한다. 사람인 API가 승인되면 해당 수집 부분에 API를 연결할 수 있도록 구성하는 것이 좋다. 지속 수집 및 저장 범위는 사이트 이용 조건을 반영한다.

## 7. 제안하는 첫 구현 범위

1. 사람인·잡코리아를 대상으로 소수 공고의 검색부터 상세 추출까지 자동화 테스트를 한다.
2. 서울·경기 의류 MD 공고를 동일한 데이터 형식으로 저장한다.
3. 원문과 비교해 업무·필수 조건·우대 조건이 정확히 구분되는지 확인한다.
4. 중복과 마감 상태를 처리하고 간단한 공고 목록을 만든다.
5. 샘플 정확도가 확보되면 일일 갱신 및 직무 역량 분석으로 확장한다.
6. 친구가 사용할 수 있는 전달 형태로 묶는다.

위 순서는 제안이며 아직 구현을 시작한 것은 아니다.

## 8. 아직 정하지 않은 사항

- 최종 형태: 웹앱 또는 PC 실행 프로그램 등.
- 실행 환경: 친구 PC에서 실행할지, 별도 서버에서 실행할지.
- 일일 실행 시간과 공고 수집량.
- 알림 제공 여부와 방식.
- 데이터 저장 방식과 보관 기간.
- AI 분석 사용 여부 및 비용.
